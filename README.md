# Ателье «Лекало» — веб-приложение «Швейное ателье»

Учебная практика УП 09.01. Парамонов Михаил Михайлович, группа ВД-1-23.

Сайт швейного ателье: пошив и ремонт одежды, подгонка по фигуре, костюмы для косплея.
Регистрация и авторизация, личный кабинет (мои заказы, мерки), отзывы, административная
панель с редактированием всех таблиц, пять представлений, поиск персонажа через API Shikimori,
четыре цветовые темы, переходы между страницами без перезагрузки, линейки на главной.

## Что нужно

- XAMPP 8.x (Apache, PHP 8.0 и новее, MySQL/MariaDB, phpMyAdmin)
- Браузер: Chrome, Firefox, Edge, Яндекс Браузер или Safari
- Интернет — только для поиска персонажа через API Shikimori

## Запуск

1. Скопируйте папку проекта в `C:\xampp\htdocs\atelier`.
2. В панели XAMPP запустите **Apache** и **MySQL**.
3. Откройте http://localhost/phpmyadmin → вкладка **Импорт** → выберите файл
   `sql/sewing_atelier.sql` → **Вперёд**. Скрипт сам создаст базу `sewing_atelier`.
   (Если база уже создана вручную, импортируйте в неё `sql/sewing_atelier_tables.sql`.)
4. Откройте http://localhost/atelier/

Если у MySQL задан пароль, укажите его в `includes/config.php`.

## Структура (БЭМ)

```
index.php, services.php, works.php, measurements.php, reviews.php, contacts.php
login.php, register.php, logout.php, account.php, admin.php
includes/        подключение к БД, общие функции, шапка, подвал, описание таблиц админ-панели
handlers/        обработчики форм
assets/css/base  шрифты, темы (CSS-переменные), сброс, типографика, сетка
assets/css/blocks  один файл на БЭМ-блок: header, nav, button, card, form, table, modal…
assets/css/pages   стили отдельных страниц
assets/js/app.js  реестр инициализаций блоков
assets/js/blocks   скрипты блоков: тема, меню, переходы без перезагрузки, линейки, маска телефона, проверка форм, фильтр, модальное окно
assets/js/pages    скрипты страниц: поиск персонажа (API Shikimori), админ-панель
api/             прокси к API Shikimori
sql/             дамп базы данных
```

Классы записываются как `блок__элемент--модификатор`. Чтобы убрать функцию,
удалите файл её блока и строку подключения в массиве `$page` страницы.

## API

[Shikimori](https://shikimori.io/api/doc) — открытый API базы аниме, манги и ранобэ, без ключа.
Используется на странице «Услуги и цены» в блоке «Костюм персонажа». Запросы идут через
`api/characters.php` (cURL, кеш на сутки во временной папке), поэтому в PHP должно быть
включено расширение curl (в XAMPP оно включено по умолчанию).
